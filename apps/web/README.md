# Web client

Эта директория является границей будущей Web Console Bakunity Infra.

Целевой frontend по текущей архитектуре — Next.js / TypeScript, но BI-0101 **не создаёт фиктивный frontend**, пока нет отдельной задачи на Web bootstrap.

Web будет использовать REST API и те же application rules/permissions, что и Telegram.

Authoritative UX: `docs/WEB_UX.md`.
