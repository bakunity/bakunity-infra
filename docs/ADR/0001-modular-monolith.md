# ADR-0001 — Модульный монолит

**Status:** Accepted  
**Date:** 2026-08-21

## Context

Bakunity Infra объединяет домены, DNS, серверы, права, аудит и будущие deployment/monitoring возможности. На раннем этапе нужны строгие границы модулей, но нет подтверждённой причины платить сложностью распределённой системы.

## Decision

Начать как **modular monolith**:

- один основной repository;
- одна application boundary;
- явные business modules;
- контролируемые межмодульные контракты;
- внешние системы через ports/adapters.

## Consequences

Плюсы:

- быстрее развивать V1;
- проще транзакции, отладка и deployment;
- меньше operational overhead;
- модуль можно извлечь позже по реальной причине.

Ограничение: модульный монолит требует дисциплины — нельзя превращать общую БД и один процесс в разрешение импортировать всё отовсюду.

## Alternatives considered

- Набор микросервисов с первого дня — отклонено как преждевременная сложность.
- Неструктурированный монолит — отклонено из-за будущей связанности.
