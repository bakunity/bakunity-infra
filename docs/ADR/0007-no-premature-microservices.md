# ADR-0007 — Никаких преждевременных микросервисов

**Status:** Accepted  
**Date:** 2026-08-21

## Context

Количество модулей Bakunity Infra будет расти. Сам по себе рост числа модулей не означает необходимость распределённой архитектуры.

## Decision

Модуль выделяется в отдельный service только при измеримой причине, например:

- отдельный профиль нагрузки;
- независимое масштабирование;
- fault isolation;
- отдельная operational ownership;
- технологическая необходимость изоляции процесса.

## Consequences

- Новые возможности сначала проектируются как внутренние модули modular monolith.
- Background worker/queue допускаются без автоматического превращения каждого модуля в сервис.
- Любое service extraction требует нового ADR с доказанной причиной и последствиями.
